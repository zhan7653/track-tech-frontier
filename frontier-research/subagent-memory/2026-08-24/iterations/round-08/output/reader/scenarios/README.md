# 场景视图

场景页把八个机制重新组合成常见系统，而不是重复机制定义：

- [Manager–Specialist](01-manager-specialist.md)：Parent 保持控制，Child 接收 task packet 并返回候选结果。
- [并行 Coding / Research](02-parallel-coding-research.md)：共享工件、分支/patch、并发 merge 与 evidence lineage。
- [长期 Persistent Fleet](03-persistent-fleets.md)：多租户 scope、长期 identity、治理服务、撤销和 audit。
- [跨 Runtime 协作](04-cross-runtime.md)：identity mapping、transport 与 memory semantics 的错位。

这些页面用于从实际 topology 选择需要阅读的机制深潜；它们不是产品选型建议。
