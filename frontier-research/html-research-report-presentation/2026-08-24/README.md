# 技术前沿调研报告的 HTML 展示机制

本快照研究怎样把多文件、证据密集的 Markdown 技术调研套件转换成更容易理解、检索和复查的静态 HTML。证据截止到 2026-08-24。

默认从[读者入口](reader/README.md)开始。最短路径是[结论总览](reader/overview.md) → [展示架构](reader/architecture.md) → [方案全景](reader/solution-landscape.md)。实现相关的直接输入在[五个项目深挖](reader/projects/README.md)，检索与筛选过程在[审计入口](audit/README.md)。

这份研究只给出描述性机制与本仓库的实现边界，不把某个外部框架宣布为通用赢家。
