# Round 06 技术地图变化

一级结构继续稳定，本轮改变的是地图表达方式：

- 每个分支都区分 runtime primitive、governance/control-plane 能力和 research-frontier 机制；
- “持久化”拆成 checkpoint 恢复、thread/layout identity、project/user learning 与 team sharing；
- “共享”拆成 object/file/current-value/event/patch/belief 等权威对象；
- “安全”改为 inheritance→local execution→return/summary→shared memory→retrieval/action 的传播链；
- “评价”改为八类可独立测量对象，不允许一个 Memory 分数覆盖全链；
- “趋势”区分成熟 runtime 中常见的 primitive、正在进入工程的 control plane 与仍偏研究的 transaction/provenance/negative-transfer 机制。
