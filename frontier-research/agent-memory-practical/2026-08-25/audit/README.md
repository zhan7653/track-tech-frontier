# 审计入口

本目录保存本次套件的研究契约、来源、claims、evidence、筛选和出版清单。读者先从 [reader/README.md](../reader/README.md) 开始；审计记录不承担新的技术结论。

## 主要记录

- `brief.md`：读者、范围和证据口径；
- `sources.jsonl`：已打开的一手来源；
- `claims.jsonl` / `evidence.jsonl`：正文关键判断与定位；
- `deliverables.jsonl`：读者文件清单与哈希；
- `research_plan.json`：时间窗口、证据 lane 和目标；
- `update-delta.md`：相对 v10 的结构与重点变化。
