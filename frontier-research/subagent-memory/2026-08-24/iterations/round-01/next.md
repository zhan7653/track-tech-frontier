# Round 01 问题与下一轮目标

## 仍存在的问题

- 输入低于基准规模，Semantic Scholar 受限，引用与作者/组织路线未展开。
- Parent-to-child delegation 的论文少于 shared-memory 论文，需从 runtime code 和安全研究补足。
- GitHub 候选噪声大，尚未完成 canonicality、commit、release、license、CI 和机制映射。
- Benchmark、产品/runtime、协议和负面证据还没有独立深包。
- 七个分支只有入口解释，没有达到基准的可重建深度。

## Round 02 目标

扩展论文、GitHub、Benchmark、产品与负面查询；显式补 12 个月和 90 天；按机制术语、作者、组织、论文代码和项目别名扩展；把 mapped corpus 提升到足以检验七分支边界和新增一级分支的程度。
