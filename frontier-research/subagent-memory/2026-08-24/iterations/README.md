# 迭代档案

本目录保存 5–10 轮实质性迭代。每轮都必须包含本轮输入、查询与发现、筛选变化、技术地图变化、深挖内容、完整读者输出快照、相对上一轮的差异、问题与下一轮目标，以及相对 `agent-memory-v10` 的评估。

纯格式调整、机械扩写和只增加引用不算有效迭代。

1. [Round 01：Pilot 与初始地图](round-01/README.md)
2. [Round 02：广度扩展与 runtime 输入](round-02/README.md)
3. [Round 03：分支覆盖诊断与 gap fill](round-03/README.md)
4. [Round 04：论文、算法、Benchmark 与反证深核验](round-04/README.md)
5. [Round 05：固定版本 Runtime 与仓库工程深潜](round-05/README.md)
6. [Round 06：跨来源综合与横切约束](round-06/README.md)
7. [Round 07：读者版整合与结构回归](round-07/README.md)
8. [Round 08：证据发布、饱和封账与严格验证](round-08/README.md)

每轮 `output/` 都保存当时完整 reader/audit 快照；后续修改不回写历史版本。
