# v09 acceptance gates

The authoritative requirements are `input.md` and `..\USER_FEEDBACK.md`. The numeric targets for this Memory run are calibrated after the pilot and saved in the bundle research plan; they are not universal Skill defaults.

The run is accepted only if all gates pass independently:

- breadth;
- freshness;
- map and cluster quality;
- per-cluster depth;
- consensus and contradiction quality;
- cross-source synthesis;
- GitHub engineering usefulness and recent-trend sensitivity;
- deep claim/evidence correctness;
- multi-file deliverable integrity;
- direct behavioral comparison with the named research systems.

Schema validation is necessary but insufficient. v08's previous score does not carry forward.

## Pilot-calibrated minimums for this run

The 2026-08-10 pilot returned 397 arXiv candidates for one phrase family, a very noisy Crossref universe, and 52,649 GitHub matches for one deliberately broad query; in the first 100 GitHub results, a simple metadata screen retained roughly two fifths as plausible Memory candidates. That evidence justified a high-recall funnel rather than a small bibliography.

- discover at least 900 unique entities, including 500 papers and 320 repositories;
- map at least 280 entities, including 170 papers and 100 repositories;
- deep-verify at least 75 entities, including 40 papers and 30 repositories;
- discover at least 400 and map at least 140 entities from the rolling recent windows;
- execute at least 48 logged queries across terminology, mechanism, benchmark, negative/security, alternatives, product, and repository-trend lanes;
- publish at least 10 coherent clusters, 24 reader deliverables, 120 atomic claims, 120 opened sources, and 260 evidence joins.

These are floors, not stopping rules. Saturation, cluster completeness, and independent quality gates remain decisive even after the counts are met.
