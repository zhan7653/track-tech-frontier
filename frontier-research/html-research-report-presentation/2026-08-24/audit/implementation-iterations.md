# HTML 实现与浏览器迭代

实际输入：`examples/agent-memory-v10`；最终生成 70 页、686 条页/章节搜索记录。浏览器使用本地静态服务器，不依赖远程资源。

## V1 · 结构基线

- 加入多页静态转换、套件导航、页内目录、全文搜索、主题、移动抽屉、比较表、代码块和 Mermaid SVG。
- 浏览器发现：1280px 下两侧栏把正文压到约 615px；长流程图整体缩小后标签不可读。

## V2 · 阅读层级

- 1340px 以下隐藏右目录，让正文恢复到 780px；长图按自然节点尺寸横向滚动。
- 加入同组上一篇/下一篇。
- 浏览器确认流程节点标签可直接阅读，点击节点能更新解释。

## V3 · 理解交互

- 所有长页加入章节地图；比较表加入列数、滚动和行聚焦提示；页面元数据显示节/图/表数量。
- 搜索结果限制同页最多三条、使用中文类型标签、键盘可直接落到章节。
- 修复搜索结果把本地索引文本直接插入 `innerHTML` 的问题，所有字段先转义。

## V4 · 韧性与视觉收尾

- 缩小超长专题标题，手机隐藏冗余专注按钮；加入 no-script 提示、主题与搜索 ARIA 状态。
- 构建清单不再写本地绝对路径。
- 浏览器确认 1440×900 有三栏目录、390×844 无页面级横向溢出，深色主题状态正确，控制台无错误。

## V5 · 文本图兼容

- 兼容四空格缩进代码块并保持等宽/换行/复制；现有 fenced ASCII 安全链图在浏览器中保持完整。

## V6 · 静态资源收口

- 增加本地 SVG favicon，消除预览服务器的自动图标 404；默认输出继续保持零 CDN 和零服务依赖。

## V7 · 独立安全核验修复

- 独立 Power Check 发现资源覆盖、root 外链接、陈旧输出和 fragment 校验缺口。
- 资源只允许被动类型并复制到 `assets/source/`，不能覆盖页面、`site.js` 或保留资源。
- root 外本地链接改成非点击“源工作区”文本并进入 manifest；standalone 站点不再包含越界链接。
- 构建改为 staging 验证后原子替换；只替换 manifest 文件集合与哈希完全匹配的旧输出，额外用户文件会阻止替换。
- 旧目录移入随机 backup 后、安装新目录与删除 backup 前都会再次核对 ownership/hash/file-set；并发写入会恢复原目录并中止。
- `--check` 复核源/输出/资源哈希、完整文件集合、搜索目标和 HTML fragment；删除或改名 Markdown 后不会留下旧页面。

## 最终验收

- 桌面：1440×900，正文约 775–780px，右目录可见。
- 默认 1280px：右目录收起，正文 780px。
- 手机：390×844，正文宽 343px，套件导航为抽屉，流程图在局部容器内滚动。
- 搜索：“主动检索”返回章节级结果；方向键 + Enter 跳到精确锚点。
- 图解：5 个 Mermaid flowchart 生成 SVG + 对象/连接文本 + 原始源码。
- 控制台：无 error/warning。
