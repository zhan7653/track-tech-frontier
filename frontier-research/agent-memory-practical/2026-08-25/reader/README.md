# 读者入口

这套报告从 Codex 的公开 Memory 实现抽象出七层 Agent Memory 架构：输入、写入与形成、状态/存储/索引、管理与演化、读取/检索/上下文、使用/行动/技能、反馈/经验/持续学习。

## 推荐阅读顺序

1. [总览与通用架构](overview.md)：先看一条完整数据流和七层各自承担的工作。
2. [第 1 章：输入层](01-input.md) 到 [第 7 章：反馈层](07-feedback-learning.md)：逐层看 Codex 当前实现，以及论文和仓库正在补充的机制。
3. [Codex 完整工程说明](codex-complete.md)：从固定 commit 重建组件、数据库、文件工件、读取路径、反馈和限制。

主阅读路径只有上面的总览、七章和 Codex 完整说明。`architecture.md`、`trends.md`、`github-radar.md`、`scenarios.md` 等文件是旧版工具需要的兼容/导航入口，不代表还有一组未完成的主章节。

## 每章的阅读方式

每章都按同一条线展开：先给当前层的职责，再说明 Codex 中对应的组件和数据流，然后放入有直接论文或仓库证据的近期机制，最后说明成熟度和边界。近期材料数量随该层的技术变化而定，不做固定配额。

## 证据标记

- **代码事实**：来自固定 commit、官方仓库或可定位的实现路径。
- **官方说明**：来自项目文档、发布说明或 issue；issue 只表示问题报告。
- **论文/原型**：来自论文原文或作者提供的代码，结果只适用于论文给出的协议和数据。
- **报告判断**：在前述材料基础上的限定性归纳。

论文和原型会明确写出成熟度。GitHub Star 只用于去除明显低关注噪声，不承担质量、性能或生产采用证明。
