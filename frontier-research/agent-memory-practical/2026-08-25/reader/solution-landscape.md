# 方案全景兼容入口

本套件按七层实现组织方案，不按产品名称或数据库品牌组织。

## 全领域的方案坐标

| 位置 | 当前常见做法 | Codex 对应形状 |
|---|---|---|
| 形成 | 原始保留、摘要、事实抽取、Agent 操作 | 两阶段模型形成 |
| 状态 | 数据库、文件、图、多后端投影 | SQLite 候选账本 + Markdown 工件 |
| 读取 | 词法、BM25、向量、图、主动检索 | 摘要常驻 + 词法渐进读取 |
| 管理 | 规则、巩固、事务、学习型控制器 | usage/recency、notes、Phase 2 |

详细解释见[总览](overview.md)和七个功能章节。

## 工程实现的四种外形

公开实现常见四种组合：文件化本地 Memory、外部事实服务、多后端治理服务、由 Agent 主动调用的 Memory 工具。具体项目的组件和边界见[Codex 完整说明](codex-complete.md)。
