# Agent Memory：从 Codex 抽象的七层架构与近期进展

**模式：** Codex-derived reader snapshot
**证据截止：** 2026-08-25
**默认读者：** 不以技术工作为主、但需要看懂 Agent Memory 真实实现的人
**默认入口：** `reader/README.md`，主入口为 `reader/overview.md`

## 交付目标

从公开的 Codex Memory 实现抽象出一套描述性的七层架构，再用近 90 天优先、半年兜底的论文、官方文档和可检查仓库说明每层正在发生的变化。报告以当前实现和数据流为主，概念只用于解释实现。

文档套件由以下部分组成：总览与通用架构、七个功能章节（输入、写入与形成、状态/存储/索引、管理与演化、读取/检索/上下文、使用/行动/技能、反馈/经验/持续学习），以及一章独立的 Codex 完整工程说明。

## 证据口径

- Codex 的成熟基底以固定版本代码、官方仓库文档和公开 issue 为主；托管产品行为只在官方材料明确说明时引用。
- 近期内容以论文原文、作者/机构页面、官方仓库或固定版本代码为入口。GitHub Star 只用于去掉明显低关注噪声，不承担质量或采用证明。
- 论文、原型和工程实现分开标注；“提出机制”不写成“已经成为主流”。
- 每章按实现数据流组织：通用层职责 → Codex 对应实现 → 近期补充/变化 → 当前边界。

## 范围外

不做产品选型、部署方案、实现清单或统一性能排名；不把普通 RAG、上下文压缩、模型参数记忆和团队规则文件单独当作 Agent Memory 主体，除非它们承担跨会话状态生命周期职责。
